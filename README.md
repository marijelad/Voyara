# Voyara — Smart Travel Planner

A polished, fully static multi-page travel planning portfolio project built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Highlights

- 30+ connected HTML pages
- 14 destination detail pages with original local SVG artwork
- Smart itinerary generator
- Browser-saved trips and favorite destinations via localStorage
- Budget estimator
- Destination and listing filters
- Drag-and-drop itinerary board
- Dark mode
- Responsive navigation and layouts
- Lightweight PWA manifest and service worker
- No required external APIs, frameworks, fonts or image hosts

## Run locally

Open `index.html` directly, or for service-worker testing run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Upload all files to a repository, then enable Pages from the repository settings using the main branch/root directory.

## Important

Voyara is a fictional portfolio concept. Prices, ratings, stays, activities and restaurant listings are illustrative. Replace legal/contact copy before adapting for production.
